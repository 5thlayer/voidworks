# Void starts in the Overworld, before the End

The spec first made void post-End: the Void Siphon needed dragon's breath, every Void Displacer's
recipe needed motes, and so the Siphon in the End was the only way in. The spec also says the End is
the reservoir and the Nether the turbine, which a player could not learn until after the dragon.

**Decision.** The first Void Displacer is the Overworld's, at the diamond tier: crying obsidian,
ender pearls and a sticky piston, costing no motes. It needs no network to start, because it grows
its own: it harvests outward from itself, and what it has harvested is the network its motes go
into. Its motes pay for a Mutation Chamber before the Nether, at the Overworld's low value. The
Void Siphon's recipe moves to a ghast tear, crying obsidian and a blaze rod, so a player carries
Overworld motes down to the Nether, where they first pay well. Every later void machine is placed
Dormant and soaks its cost where it stands, which makes a Siphon's End harvest the only thing that
can pay for the End's Displacer. Dragon's breath moves to a higher Siphon tier, and the Void Well
arrives after the dragon with the Void Dragon, from End-city shulker shells.

Crying obsidian is what steers the loop: before the Nether it comes only from ruined portals, enough
for a Displacer or two, and after it piglins barter it, so relocating Displacers pulls a player into
the Nether.

## Considered options

- **Void stays post-End**, the Siphon first: the Nether lesson waits for the dragon, and nothing
  starts a base but a Siphon.
- **Void before the End, but nothing crosses dimensions until the dragon**: Overworld motes earn only
  their lowest value for the whole of the mid game.
- **An iron-tier Overworld Displacer**, renewable in the Overworld alone: void starts sooner, but
  nothing pushes relocation into the Nether.

## Consequences

- A Displacer reaches only what is connected to it, so a cave or an air pocket bounds what it can
  convert, and its Zone is a count of harvests rather than a region.
- Only blocks a Density tag names can be harvested; everything else, the renewable and abundant
  blocks above all, is Density 0, so a cheap generator never becomes a source of motes or Voidstone.
- A Displacer's network stalls it when full, and each Voidstone holds about its own harvest, so
  Voidstone bodies are a base's storage until the Void Well comes with the Dragon.
